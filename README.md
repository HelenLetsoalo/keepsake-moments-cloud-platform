# Keepsake Moments Cloud Platform

## Project Overview

Keepsake Moments Cloud Platform is a portfolio project that explores how to design and build a cloud-based e-commerce platform using Amazon Web Services (AWS).

The fictional business sells personalised gift boxes. The platform will allow customers to browse products and submit orders while providing a secure and reliable environment for managing business data.

## Business Requirements

The platform should eventually support:

- Viewing available gift boxes and their prices.
- Submitting customer orders.
- Storing product images.
- Storing and retrieving order information.
- Protecting customer and business information.
- Supporting increased customer traffic during busy periods.

## Planned AWS Services

| AWS Service | Planned purpose |
|---|---|
| Amazon VPC | Network isolation and architecture |
| Amazon EC2 | Application computing |
| Amazon S3 | Website and product image storage |
| Amazon RDS | Relational database |
| AWS IAM | Identity and access management |
| Amazon CloudWatch | Monitoring |

These services are planned components. They will be introduced and tested as the project progresses.

## Learning Objectives

This project aims to demonstrate practical understanding of:

- Cloud computing fundamentals.
- AWS networking and infrastructure.
- Compute and storage services.
- Relational databases and SQL.
- Cloud security and permissions.
- Scalability, availability and cost management.
- Technical documentation and troubleshooting.
